# Plan 30.1-01 — Probe authored, snapshot captured, Wave 2 routed

## What landed

Authored `scripts/probe-openrouter.ts`, a standalone OpenRouter free-tier
rate-limit probe that imports `OPENROUTER_DEFAULT_MODEL` from
`server/lib/freeClaudeRouter.ts` (which gained an `export` keyword as part of
this plan — Edit 1) so the probe always measures whatever model the
production cascade actually uses. The probe runs 30 single-event payloads
with a 100ms inter-call gap, classifies each outcome (rate_limit / ok /
other_error) using the same 429 / "rate limit" substring check as
`server/lib/freeClaudeRouter.ts:classifyError`, and writes a byte-stable
snapshot via atomic tempfile-rename. Per-attempt logging goes through
`logger.child({ module: 'probeOpenRouter' })`; only the final summary + decision
hint use `console.log`. The error catch block captures `errorMessage` (truncated
to 200 chars) and the `retry-after` header (when finite) — no raw response bodies
or other headers ever serialized (T-30.1-01 mitigation).

`package.json` got a `probe:openrouter` script using the same
`--env-file-if-exists` runner shape as `eval:replay` / `refresh:water`.
