## Definition of Done

Per `.planning/PROJECT.md` Current Milestone block, v1.4 covered three concurrent tracks against the stabilized v1.3 codebase:

1. **GDELT pipeline redo (Phase 27 family)** — replace the scrapped NLP approach with a structured LLM extraction pipeline. Cerebras-primary / Groq-fallback / NIM v3 progression. Geocode resolver. Dev dashboard observability.
2. **Performance & operational hardening (Phase 28 family)** — cleanup sweep + dev/prod sync + domain rename + green-light gate + cron architecture fix + audit-tier completeness.
3. **Load test (originally Phase 28.3)** — k6 sweep against the stabilized prod surface to validate 1–300 concurrent users.

## Achievement Summary

### Track 1: GDELT redo (12 phases, all shipped)

- **27 → 27.4.6**: pipeline cutover from CAMEO classification fallback through v1 (Cerebras), v2 (watchdog + DLQ), to v3 (NIM with parallel concurrency limiter). Daily cron triggers extraction. Lazy on-demand bridge from v3 → v2 → v1 → raw GDELT preserves "map never goes blank" guarantee through cutover.
- **Geocode resolver**: 6-path location resolver (own-site-snapshot → POI Nominatim → constrained Nominatim → 2-pass verify → GDELT ActionGeo fallback → Bellingcat coord passthrough). 1-req/s Nominatim throttle. 30-day Redis cache.
- **Eval harness**: ground-truth-events.json (50 curated events across 11 countries) scored at 5/20/100km thresholds via inline haversine. Daily eval run folded into `/api/cron/health`. 90d baseline retention.
- **Adversarial robustness**: ~10 prompt-injection fixtures validate v3 prompt resists exfiltration/jailbreak attempts. Result surfaced in API Health tab.
- **Reliability primitives**: circuit breaker (sliding 10-call window, 5min pause on >30% error), DLQ (200-entry SADD bounded set, 7d TTL), token budget (per-provider daily caps with soft 0.8 / hard 0.95 thresholds), watchdog (90s hard kill + 60s soft warn, late-resolve guard).

### Track 2: Performance & operational hardening (5 phases + umbrella, all shipped)

- **28.1 Cleanup sweep**: ghost code deletion (knip + ts-prune triage), 12 operator-tunable env vars, domain constants centralized, CSS `@theme` color tokens, 0 TypeScript errors / 0 lint warnings baseline restored.
- **28.2 Dev/Prod sync**: domain rename → `otg-iran-monitor.vercel.app`, Bearer-bypass rate limiter, operator-endpoint Bearer gates, dev-only field promotions to Bearer-gated prod, dashboard surfaces merged into `API Health` tab, manual-trigger `prod-connectivity-audit.yml` workflow.
- **28.2.5 API green-light gate**: `events:llm:v3` registry promotion, weather tooltip distance hint, tier-green assertion in audit workflow, sidecar Redis key `audit:connectivity:last-result`.
- **28.2.6 Cron architecture fix**: Vercel `waitUntil` for fire-and-forget durability, incremental terminal-key writes, cold-cache self-heal, operator force-trigger via `?force=true`.
- **28.2.7 Audit-tier completeness**: cron `lastTick:<name>` writers (R1), `llm:lastProgress` Redis write-through + Redis-first probe (R2), `probeProbeOnly` honest stub (R3) — all 3 falsifiable requirements verified in prod.
- **Compounding fixes during 28.2.7 closeout**: rate-limit companion test target retargeted (`/api/health` → `/api/audit-status` since `/api/health` is intentionally unthrottled, mount-order pre-Phase-28.1 W2); `llmStatus` freshness widened from 5min → 26h (matches daily cron cadence); `llmEvents` probe gains v3 → v2 → v1 fallback chain mirroring `/api/events` cache bridge. PR #15 + #16 merged 2026-05-08.

### Track 3: Load test (deferred)

- **28.3 → 999.5 backlog**: deferred at v1.4 close because the prerequisite `prod-connectivity-audit.yml` tier-green gate had two upstream blockers: (a) v3 NIM extraction not consistently populating `events:llm:v3` within Vercel function budget under intermittent NIM throttle; (b) cold-cache races in fire-and-forget dispatch. These are pipeline ops/scheduling concerns, not load-test design defects. CONTEXT.md preserved verbatim at `.planning/phases/999.5-performance-load-test/999.5-CONTEXT.md`. Promotion gate: 3 consecutive `prod-connectivity-audit.yml` runs exit 0 with `allTiersGreen=true`.
