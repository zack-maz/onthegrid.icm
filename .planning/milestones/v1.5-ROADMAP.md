## Overview

v1.5 narrowed the v3 LLM extraction cascade to NIM-only (OpenRouter declared dormant after probe-driven evidence), deleted the v1 + v2 extractor modules and their override surface entirely, upgraded Vercel to Pro for the 800s `maxDuration` ceiling, and proved the map renders cleanly on raw GDELT when no LLM keys are present (Pitfall 1 cache bridge). Ghost-event URL liveness probing, dashboard surfacing, and Bearer-gated pruning shipped as the GHOST track. Actor metadata gained a canonical catalog with `actorConfidence`, eval expansion to actor-match rate, and dashboard surface. Internal docs gained a Redis registry drift gate (39 assertions) + a 32-key inventory doc + JSDoc audit + bundle-size measurement. Public docs surface (README, 12 architecture markdown files, 21 Mermaid diagrams, SRE runbook, degradation contract) brought into v1.4 + v1.5 reality; OpenAPI 3.0.3 spec extended from 14 → 19 endpoints with split securitySchemes. ADR-0010 captures the milestone-final shipped state. LLM-RELI-07 acceptance gate hit: 3 consecutive `prod-connectivity-audit.yml` exit-0 runs with `allTiersGreen=true`, unblocking 999.5 (k6 1–300 VU sweep) for v1.6 promotion.
