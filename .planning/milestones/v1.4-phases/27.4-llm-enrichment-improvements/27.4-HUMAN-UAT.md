## Tests

### 1. End-to-end v2 pipeline — Events tab visibility + 8 blocks render

expected: With `LLM_PIPELINE_V2=true` in local dev environment, open DevApiStatus modal and confirm the 'Events' tab appears. All 8 blocks should render: pipeline waterfall, precision/confidence/source-tier/casualty histograms, per-event drill-down (last 50) with copy-prompt button, LLM call log (last 20), per-provider budget bars, eval score summary with D-25 gate PASS/FAIL, DLQ recent list, suspect count badge. "Paused — soft cap" badge should appear when either provider crosses 80% of daily token budget.

result: [issue]

issue: V2 extractor stalled at batch 133/184 during live verification session 2026-04-21 because `server/lib/llmEventExtractor.v2.ts` only writes `events:llm:v2` cache after all batches complete and lacks a per-batch timeout watchdog. One hung Cerebras call lost ~45 min of LLM work. `schemaVersion` never advanced from `v1` to `v2`, so the Events tab never rendered. Root cause + fix shape documented in `27.4-HANDOFF.md` section "P0 — v2 extractor incremental cache flush + watchdog". Linked to follow-up Phase 27.4.1.

why_human: Tab visibility gate is `schemaVersion==='v2' && import.meta.env.DEV` — requires an actual LLM pipeline run to populate `llmStatus.schemaVersion`.

### 2. Cold-start v2→v1 graceful fallback

expected: With `LLM_PIPELINE_V2=true`, trigger a `/api/events` cache miss and confirm: (a) v2 extractor runs and writes to `events:llm:v2` Redis key, (b) map renders events normally, (c) `/api/events/llm-status` shows `schemaVersion='v2'` + populated `evalScore`, (d) no blank-map regression during cold start. Then manually drop `events:llm:v2` and confirm v2→v1 fallback serves stale v1 data gracefully.

result: [passed]

pass_note: The Pitfall 1 bridge was observed working during the 2026-04-21 verification session. With `events:llm:v2` empty (v2 extractor hung — see test 1) and `events:llm` populated with 296 enriched v1 events, `/api/events` served the v1 payload and the map rendered normally — no blank-map regression. The graceful-degradation contract (map never goes blank) is validated. Full v2→write→drop→v1 cycle deferred until Phase 27.4.1 lands the watchdog fix so that v2 can actually complete a run.

why_human: End-to-end pipeline behavior requires real LLM provider calls (Cerebras/Groq) and live Redis cache manipulation.
