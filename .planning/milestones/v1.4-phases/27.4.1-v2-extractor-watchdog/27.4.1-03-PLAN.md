<objective>
Close Phase 27.4's P0 defect. After this plan merges, a single hung Cerebras call can no longer cost 45+ minutes of completed LLM work — each successful batch writes through to Redis immediately, and a per-batch watchdog kills any call that hangs past LLM_BATCH_TIMEOUT_MS (90s default).

Purpose: The shipped v2 extractor accumulates results in a local `results` array and only writes to `events:llm:v2` after the FINAL batch succeeds (no cacheSetSafe anywhere inside `processEventGroupsV2`). The stall reproduced at batch 133/184 on 2026-04-21 proved this is a P0 issue. This plan layers in the durability primitives from Plan 01 without changing the extractor's public contract or the events.ts caller.

Output: Enhanced `processEventGroupsV2` that: (1) imports `withBatchWatchdog` from Plan 01, (2) wraps each batch call, (3) writes a partial `LLMCachePayload` envelope after every successful batch, (4) DLQ-routes timed-out groups with `reason='timeout_watchdog'`, (5) writes final `complete: true` snapshot. Plus 3 new Vitest cases covering each new behavior.
</objective>

    /**
     * Phase 27.4.1 D-07/D-08/D-10 — write a partial/final snapshot of the
     * in-progress events array to events:llm:v2. Wrapped in cacheSetSafe so
     * Redis failures don't propagate (D-29). `complete: true` is written

     *

     * (server/routes/events.ts) currently reads v2 as ConflictEventEntity[]
     * — during the rollout window, the envelope's `events` field carries
     * EnrichedEventV2[] (pre-geocoding shape), which the route layer
     * transforms via enrichedV2ToEntities AFTER the full run completes.
     * The Pitfall 1 bridge (D-09) continues to serve v1 when the v2 cache
     * is empty OR shaped like an envelope (reader reads ConflictEventEntity[]
     * and finds a non-array), so partial-to-user is naturally suppressed.
     * Partial-v2 reader semantics are explicitly deferred per CONTEXT.
     */
    async function writePartialCache(
      events: EnrichedEventV2[],
      completed: number,
      total: number,
      complete: boolean,
    ): Promise<void> {
      const payload: LLMCachePayload = {
        events,
        progress: `${completed}/${total}`,
        complete,
        generatedAt: new Date().toISOString(),
      };
      try {
        await cacheSetSafe(EVENTS_LLM_V2_KEY, payload, LLM_REDIS_TTL_SEC);
      } catch (err) {
        // cacheSetSafe already swallows internally, but belt+suspenders.
        log.warn({ err, completed, total, complete }, 'partial cache write failed');
      }
    }
