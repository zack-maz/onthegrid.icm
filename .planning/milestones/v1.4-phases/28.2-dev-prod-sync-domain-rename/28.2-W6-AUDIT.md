## Audit Procedure

### Local Pass (Task 4 — smoke check, NOT the gating evidence)

Per CONTEXT D-25: "Local pre-flight is acceptable as a smoke check, but the gating evidence for W6 is the prod-URL run." Local-dev requires `npm run dev` running with real upstream connectivity (GDELT, OpenSky, Yahoo Finance, etc.) — not always reachable from a CI/agent context. The gating evidence is the prod-URL run captured at Task 9 close.

To run locally (operator pre-flight, optional):

1. `npm run dev` (Vite + Express via tsx) — verify both servers are up at `http://localhost:5173` (Vite) + `http://localhost:3001` (Express)
2. `API_BASE_URL=http://localhost:5173 DASHBOARD_PASSWORD=<dev-default> RUN_CONNECTIVITY_TEST=1 npx vitest run src/__tests__/api-connectivity.test.ts`
3. Record pass/fail per endpoint in the `Local pass` column.
4. For each FAIL: diagnose via curl + DevApiStatus modal, fix with atomic commits, re-run.

The smoke suite skips by default during regular `npx vitest run` (via `RUN_CONNECTIVITY_TEST` env-flag gate) so cold-cache + non-running-server scenarios don't pollute CI's normal test pass.

### Prod Pass (Task 9 — phase-close gate per D-25)

1. Trigger `.github/workflows/prod-connectivity-audit.yml` from GitHub Actions UI (manual `workflow_dispatch`).
2. Workflow runs both `api-connectivity.test.ts` (smoke) and `rate-limit.test.ts` (D-30 companion) against `https://otg-iran-monitor.vercel.app` with `DASHBOARD_PASSWORD` Bearer.
3. Workflow writes `audit:connectivity:last-result` to Upstash Redis (7d TTL).
4. The merged DevApiStatus API Health tab reads `/api/audit-status` and surfaces the green banner `All 16 endpoints connecting (last verified <date> via prod audit).`.
5. Record pass/fail per endpoint in the `Prod pass` column.

## Companion Test (D-30)

Per CONTEXT D-30 + checker B-6: `src/__tests__/rate-limit.test.ts` sends 70 unauthenticated requests to `/api/health` (NOT `/api/flights`, because flights' 120/min per-endpoint cap triggers BEFORE the 60/min global tier; `/api/health` has no per-endpoint cap so a 429 there proves `rateLimiters.public` is firing — exactly D-30's contract).
