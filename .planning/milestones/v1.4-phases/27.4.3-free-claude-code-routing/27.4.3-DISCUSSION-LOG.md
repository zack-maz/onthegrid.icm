## Integration shape

### Round 1 (initial)

| Question                                             | Selected                         |
| ---------------------------------------------------- | -------------------------------- |
| Architecture: How should free-claude-code integrate? | Run the uvicorn proxy            |
| Hosting: If we run the proxy, where does it live?    | "any other free options?" (open) |
| Source: How do we depend on free-claude-code code?   | Vendor under server/adapters/    |

**Conflict identified:** "Run the uvicorn proxy" + "Vendor under server/adapters/" can't both be primary. Vendoring implies rewriting the Python proxy as TypeScript, which means NOT running uvicorn.

### Round 2 (reconciliation)

| Option                                         | Description                                                                                                                                                                                                               | Selected |
| ---------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------- |
| Vendor in-process (no proxy hop)               | Port translation + rate-limit + provider routing logic to TypeScript under server/lib/freeClaudeRouter.ts. v3 extractor calls these functions directly. No http hop, no separate service, no Python runtime, fits Vercel. | ✓        |
| Real uvicorn proxy on Oracle Cloud Always Free | Run free-claude-code as-is on Oracle Cloud (2 ARM VMs, free forever). Adds http hop and separate infra. Persistent rate-limiter state.                                                                                    |          |
| Real uvicorn proxy on Render free              | Same as Oracle but Render free tier sleeps after 15min idle, cold-start ~30s.                                                                                                                                             |          |
| Real uvicorn proxy local-dev only              | Run proxy on dev machines for eval/feasibility scoring. Production stays on Cerebras+Groq. Phase becomes 'tested but not shipped'.                                                                                        |          |

**User's choice:** Vendor in-process (no proxy hop)

**Notes:** User's "anything else free?" question surfaced Oracle Cloud Always Free as the only meaningful free-forever tier for a long-running uvicorn service. User then confirmed the cleaner reconciliation: vendor the proxy _logic_ (translation + rate-limit + provider routing) into TypeScript, not a separate service.

## Provider selection + rate-limit feasibility

**Pre-question framing:** Sequential extractor (~30s/batch × 184 batches = ~92 min/run) ≈ 2 req/min sustained. NVIDIA NIM 40 req/min cap = NOT binding. OpenRouter free models cap per-day per-model (~50-200/day) IS binding for primary load.

| Option                                               | Description                                                               | Selected |
| ---------------------------------------------------- | ------------------------------------------------------------------------- | -------- |
| NVIDIA NIM only — glm4.7 / kimi-k2.5                 | 40 req/min free, no daily token cap. OpenAI-compatible.                   | ✓        |
| NVIDIA NIM primary → OpenRouter free fallback        | Cascade.                                                                  |          |
| OpenRouter primary — model choice variety            | More model choice but daily caps tight.                                   |          |
| Multi-provider race — all free providers in parallel | Best latency, highest free-tier spend. Overkill given non-binding limits. |          |

**User's choice:** NVIDIA NIM only (with model-bake-off below)

| Option                                   | Description                                                                    | Selected |
| ---------------------------------------- | ------------------------------------------------------------------------------ | -------- |
| GLM-4.7 (z-ai/glm4.7)                    | free-claude-code default. Recent (2025), 9B-32B class.                         |          |
| Kimi K2.5 (moonshotai/kimi-k2.5)         | MoE, multilingual, structured output. Best fit for Persian/Arabic place names. |          |
| GPT-OSS-120B (OpenRouter only)           | Same as Groq fallback today. Forces OpenRouter as primary.                     |          |
| Run eval on multiple models, pick winner | Inner-loop runEval() against candidates, pick closest to 0.940.                | ✓        |

**User's choice:** Run eval on multiple models, pick winner

| Option                                  | Description                                                                                                          | Selected |
| --------------------------------------- | -------------------------------------------------------------------------------------------------------------------- | -------- |
| Hard fail to raw GDELT                  | When free-tier exhausts, pipeline degrades to raw GDELT. Matches 'replace entirely'.                                 |          |
| Soft fall-through to next free provider | Per-provider cap tracker; on hit, route to next free provider in cascade (NVIDIA NIM → OpenRouter free → raw GDELT). | ✓        |
| Escape to paid Cerebras/Groq            | Contradicts 'replace entirely'.                                                                                      |          |

**User's choice:** Soft fall-through to next free provider

**Notes:** "Free providers" cascade clarified in CONTEXT.md as NVIDIA NIM → OpenRouter free models. DeepSeek is paid (free-claude-code lists it but it's NOT free). LM Studio / llama.cpp are local — out of scope for serverless deploy.
