## Anti-Patterns to Avoid

Drawn from RESEARCH §11 (27.4.3 Plan 05 Gate B FAIL evidence) and 27.4.x phase history.

### A1 — Trusting bake-off small-sample latency (RESEARCH §11.A1)

**Don't:** lock a winner from a 10-event sample. Plan 03's qwen p50 17.8s in sample exploded to p99 929s in production.

**Do:** D-02 mandates 50-event LLM-in-loop bake-off before any cutover lock. D-03 dual hard floors are calibrated against this scale.

### A2 — Single Gate B run as cutover signal (RESEARCH §11.A2)

**Don't:** declare cutover-ready on one Gate B run. Plan 05 had no second-data-point to distinguish "model long-tail" from "infrastructure flake."

**Do:** D-10 mandates 2 consecutive Gate B passes. D-11 mandates strict failure semantics ("any pass missing any gate = overall fail + defer").

### A3 — Skipping pre-flight characterization (RESEARCH §11.A3)

**Don't:** run full Gate B without instrumented preflight. Plan 05 burned 218 minutes discovering the long-tail signature in production.

**Do:** D-05 preflight runs 20 batches in instrumented mode FIRST. RESEARCH §3 (lines 197-273) gives the exact streaming-instrumentation shape.

### A4 — No data-driven max_tokens cap (RESEARCH §11.A4)

**Don't:** ship without per-model token caps. qwen burned reasoning tokens on `<think>` blocks under prompt complexity.

**Do:** D-06 reads `MAX_TOKENS_PER_MODEL` from D-05 preflight measurements. Default ceiling 4096; per-model values seeded from p99(tokens-out) + 20% buffer.

### A5 — Promoting OpenRouter to prod without quota analysis (RESEARCH §11.A5)

**Don't:** propagate `OPENROUTER_API_KEY` to Vercel prod env in this phase. Free tier is ~100-200 req/day per model; production cadence (96 refreshes/day × 196 batches × cascade-on-NIM-fail) can exhaust in hours.

**Do:** D-12 keeps OpenRouter dev-only (`.env.local` only). Promotion is a future-phase decision after Gate B passes twice.

### A6 — Bake-off harness contamination via shared circuit breaker (RESEARCH §11.A6, Pitfall 2)

**Don't:** route bake-off candidates through `freeClaudeRouter.callLLM`. Per-Provider breaker tripping on one model contaminates all subsequent candidates.

**Do:** `scripts/bakeoff-v3-direct.ts` calls NIM directly via OpenAI SDK (lines 144-149). Preserve `maxRetries: 0` for precise per-call latency.

### A7 — Synthetic skip entries with wrong type contract (RESEARCH §11.A7)

**Don't:** drift from the existing `routingTrace` field set when adding the pre-warm entry.

**Do:** pre-warm entry must include `{ts, batch: -1, provider: 'nvidia_nim', model, reason: 'prewarm:cold-start'}`. `batch: -1` sentinel matches existing soft-warn pattern at the watchdog soft-warn site.

### A8 — D-19 forensic snapshot done after-the-fact (RESEARCH §11.A8)

**Don't:** capture only end-of-run snapshots. Without start-state, post-mortem can't tell whether v2 cache polluted v3 mid-run via the Pitfall 1 bridge.

**Do:** D-19 mandates start+end of EACH Gate B pass = 4 snapshots per 2-pass sequence.

### A9 — Breaking `coerceCachedEvents` defense-in-depth bridge (RESEARCH §11.A9)

**Don't:** modify the Pitfall 1 graceful fallback at `events.ts:861-879` (v3→v2→v1→raw GDELT chain). This is what kept the user-facing map non-blank during Plan 05's Gate B failure.

**Do:** preserve verbatim. Cutover relies on it as the safety net during the auto-rollback window.

### A10 (NEW) — Lineage pre-filter default ON

**Don't:** set `V3_LINEAGE_PREFILTER=true` for Gate B test runs. Cached-mostly-skip path produces different telemetry than full-processing path.

**Do:** keep default OFF (D-18). Activate via env flag post-cutover when ongoing-ops cost optimization > telemetry purity.

### A11 (NEW) — Adaptive batching always-on

**Don't:** set `V3_ADAPTIVE_BATCH=true` for Gate B test runs. Always-on adaptive batching changes the watchdog-timeout signature (split-and-recover doesn't increment `watchdogTimeoutCount`) — this changes Trigger 1 behavior.

**Do:** keep default OFF (D-04). Activate only when bake-off reveals winner p95 > 20s OR production smoke surfaces fresh long-tail.
