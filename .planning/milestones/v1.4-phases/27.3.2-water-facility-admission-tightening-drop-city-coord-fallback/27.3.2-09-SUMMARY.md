- **Issue:** Wave 1 Plan 01 extended the server-side `WaterFilterStats` interface in `server/adapters/overpass-water.ts`. Ordering mirrors Plan 01: new field sits between `no_name` and `duplicate`.
- **Files modified:** `src/stores/waterStore.ts` (+4 lines: 2 fields + 2 doc-comments)
- **Commit:** `cea833d` (same commit as the two DevApiStatus edits)
- **Rationale:** Rule 3 applies — blocking issue directly caused by the current task's dependency on fields that Wave 1 plans declared in the server-side interface but forgot to mirror on the client-side tier-independent interface. Plan 09's acceptance criteria require `npx tsc --noEmit` to exit 0; fixing inline is the correct call vs. escalating to Rule 4 (no architectural change — the pattern of mirrored interfaces was already established by 27.3.1 Plan 10's G2 edits for `excluded_turkey`, which DID update both server + client sides).
