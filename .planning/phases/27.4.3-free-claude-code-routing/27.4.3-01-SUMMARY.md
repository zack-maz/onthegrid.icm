## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Fix freeClaudeRouter primary-skip routing reason**

- **Found during:** Task 2 (test F1 — "NVIDIA NIM circuit-broken — routes to OpenRouter")
- **Issue:** Plan spec literal `buildReason: isPrimary ? 'primary' : ...` emitted `'primary'` for the routing decision when the primary was BYPASSED by a gate (no_client / breaker / rate_limit_window / daily_cap). Bypass became indistinguishable from a normal primary attempt in the routing trace. Test F1 expected `'breaker'` substring on `routing[0]?.reason` for the breaker-bypass case.
- **Fix:** `buildReason` now returns `skipped:<suffix>` for primary bypass and preserves `fall_through:<prev>_<suffix>` for downstream providers. Observability is now correct in both paths (call-was-made vs call-was-skipped).
- **Files modified:** server/lib/freeClaudeRouter.ts
- **Verification:** All 15 freeClaudeRouter tests green in 4.6s.
