preservation no longer earn its keep.

## Decision

1. **Narrow the active cascade.** Cerebras + Groq removed from

   importable for emergency-only reference; no production code path
   references them.

2. **Delete v1 + v2 extractor modules.** ... [enumeration]

3. **Prove the LLM-optional architecture.** Integration test + runbook.

4. **Vercel Pro upgrade landed in the same phase** so subsequent v1.5
