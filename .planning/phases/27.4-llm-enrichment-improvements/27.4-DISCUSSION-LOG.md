## Error handling + retry budget

| Option              | Description                                              | Selected |
| ------------------- | -------------------------------------------------------- | -------- |
| Bounded chain + DLQ | 2 retries, provider fallback, Redis DLQ, circuit breaker | ✓        |
| Unbounded retry     | Retry until success                                      | ✗        |
| Fail fast, no DLQ   | 1 attempt → GDELT fallback, forget                       | ✗        |

**User's choice:** Bounded chain + DLQ (recommended).
**Notes:** Preserves 27 D-06 graceful degradation; DLQ surfaces in DevApiStatus for manual triage.
