**Layered-resolver dispatch** — the 6 paths from RESEARCH.md diagram (lines 258–286):

1. **`own-site-snapshot`** — `loadSitesSnapshot()` + `loadWaterSnapshot()` exact-name match within country.
   Load pattern (`sitesSnapshot.ts` lines 51–105) returns `{ sites: SiteEntity[] }` and `{ facilities: WaterFacility[] }`. Filter by `event.location.country` (ISO A3 or country name), then `fuzzyNameMatch(landmark, site.label)`. First hit wins; provenance = `own-site-snapshot`.

3. **`nominatim-direct`** — `forwardGeocodeConstrained({ q: buildDisplayName(hierarchy), countrycodes: ME_COUNTRY_CODES, viewbox: ME_VIEWBOX, bounded: true })`.

4. **`nominatim-verified-2pass`** — triggered by sanity gate: coord > 250 km from `group.centroidLat/Lng` OR precision ≤ `city`. Fetch `limit: 5, addressdetails: true` candidates, send back to `callLLM` with the small reranker schema (RESEARCH.md Pattern 5). Provenance = `nominatim-verified-2pass`.

5. **`bellingcat-coord-passthrough`** — if `extractBellingcatGeo` (see `server/lib/eventScoring.ts` lines 188–196) returns `{ lat, lng }` for any article title matched to the group, and no prior path succeeded.

6. **`gdelt-actiongeo-fallback`** — last-resort, matches v1 lines 286–304 verbatim. Use `group.centroidLat/Lng`.

**Distance-gate helper** — reuse the inlined `haversineKm` from `server/lib/eventGrouping.ts` lines 4–12:

```typescript
function haversineKm(lat1: number, lng1: number, lat2: number, lng2: number): number {
  const R = 6371;
  const dLat = ((lat2 - lat1) * Math.PI) / 180;
  const dLng = ((lng2 - lng1) * Math.PI) / 180;
  const a =
    Math.sin(dLat / 2) ** 2 +
    Math.cos((lat1 * Math.PI) / 180) * Math.cos((lat2 * Math.PI) / 180) * Math.sin(dLng / 2) ** 2;
  return R * 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1 - a));
}
```

Inline directly — zero-dep pattern per RESEARCH.md "Don't Hand-Roll" row 3.

**Output shape** — append `geocodeProvenance: GeocodeProvenance` onto each resolved event for D-22.

**DO NOT imitate:** the Phase 26.2 `nlpGeoValidator.ts` / `titleFetcher.ts` / `compromise`-lexicon approach. ADR-0005 explicitly scrapped that path ("patching downstream of a bad signal compounds the problem"). The resolver stays deterministic and upstream of the LLM's name output — no article scraping, no second NLP pass on titles inside the resolver.

### `server/lib/llmTokenBudget.ts` (new — Redis atomic counter)

**Analog:** partial — the `shouldBackfill` + `recordBackfillTimestamp` pair in `events.ts` (lines 77–99) is the closest in-repo "Redis-backed lazy counter" idiom. The specific `INCRBY + EXPIRE` pipeline is from RESEARCH.md Pattern 7.

```typescript
async function shouldBackfill(): Promise<boolean> {
  try {
    const lastTs = await redis.get<number>(BACKFILL_KEY);
    if (lastTs === null || lastTs === undefined) return true;
    return Date.now() - lastTs > BACKFILL_COOLDOWN_MS;
  } catch {
    return true; // Redis unreachable — allow, it has its own error handling
  }
}
async function recordBackfillTimestamp(): Promise<void> {
  try {
    await redis.set(BACKFILL_KEY, Date.now(), { ex: REDIS_TTL_SEC });
  } catch {
    /* non-critical */
  }
}
```

Same `try/catch swallow → non-fatal` discipline (graceful degradation contract).

**New pattern** (RESEARCH.md Pattern 7 lines 549–580):

```typescript
import { redis } from '../cache/redis.js';
const DAILY_LIMITS: Record<'cerebras' | 'groq', number> = { cerebras: 1_000_000, groq: 200_000 };

function todayKey(provider: 'cerebras' | 'groq'): string {
  const today = new Date().toISOString().slice(0, 10);
  return `llm:tokens:${provider}:${today}`;
}

export async function incrDailyTokens(provider: 'cerebras' | 'groq', n: number): Promise<number> {
  const key = todayKey(provider);
  const [newVal] = await redis.multi().incrby(key, n).expire(key, 172_800).exec();
  return newVal as number;
}

export async function getDailyTokens(provider: 'cerebras' | 'groq'): Promise<number> {
  return (await redis.get<number>(todayKey(provider))) ?? 0;
}

export function budgetState(provider: 'cerebras' | 'groq', used: number): 'ok' | 'soft' | 'hard' {
  const limit = DAILY_LIMITS[provider];
  if (used >= limit * 0.95) return 'hard';
  if (used >= limit * 0.8) return 'soft';
  return 'ok';
}
```

Pitfall 3 guard: only increment on successful calls (the Cerebras/Groq wrapper already returns `null` on error — guard at the call site).

```typescript
type Provider = 'cerebras' | 'groq';
interface BreakerState {
  outcomes: Array<'ok' | 'err'>; // bounded to 10
  pausedUntil: number | null;
}
const state: Record<Provider, BreakerState> = {
  cerebras: { outcomes: [], pausedUntil: null },
  groq: { outcomes: [], pausedUntil: null },
};

export function record(provider: Provider, outcome: 'ok' | 'err'): void {
  const s = state[provider];
  s.outcomes.push(outcome);
  if (s.outcomes.length > 10) s.outcomes.shift();
  const errs = s.outcomes.filter((o) => o === 'err').length;
  if (s.outcomes.length === 10 && errs / 10 > 0.3) {
    s.pausedUntil = Date.now() + 5 * 60_000;
    s.outcomes = [];
  }
}

export function isAvailable(provider: Provider): boolean {
  const s = state[provider];
  if (s.pausedUntil && Date.now() < s.pausedUntil) return false;
  if (s.pausedUntil && Date.now() >= s.pausedUntil) s.pausedUntil = null;
  return true;
}
```

```typescript
export async function enqueueDLQ(entry: DLQEntry): Promise<void> {

  await redis.sadd(DLQ_KEY, payload);
  await redis.expire(DLQ_KEY, DLQ_TTL_SEC);
  const size = await redis.scard(DLQ_KEY);
  if (size > DLQ_MAX) {
    const all = await redis.smembers(DLQ_KEY);
    const parsed = all
      .map((s) => JSON.parse(s) as DLQEntry)
      .sort((a, b) => a.timestamp - b.timestamp);
    const toRemove = parsed.slice(0, size - DLQ_MAX).map((e) => JSON.stringify(e));
    if (toRemove.length > 0) await redis.srem(DLQ_KEY, ...toRemove);
  }
}

export async function listDLQ(limit: number = 50): Promise<DLQEntry[]> {
  const all = await redis.smembers(DLQ_KEY);
  return all
    .map((s) => JSON.parse(s) as DLQEntry)
    .sort((a, b) => b.timestamp - a.timestamp)
    .slice(0, limit);
}

export async function countDLQ(): Promise<number> {
  return (await redis.scard(DLQ_KEY)) ?? 0;
}
```
