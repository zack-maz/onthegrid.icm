## Sampling Rate

- **After every task commit:** Run `npx vitest run` scoped to touched module (e.g., `npx vitest run server/lib/llmEventExtractor.test.ts`)
- **After every plan wave:** Run `npx vitest run server/` (server slice)
- **Before `/gsd-verify-work`:** Full `npx vitest run` + eval harness dry run (`npm run eval:ground-truth`) must be green
- **Max feedback latency:** 15s server-only / 60s full
