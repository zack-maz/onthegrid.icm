## Post-execution fix (commit `07986c1`)

After Tasks 1-7 shipped, the operator reported the DevApiStatus dashboard's
Water + Events subtabs were missing. Two cold-start gates were the cause:

- `showWaterTab = useLayerStore.activeLayers.has('water')` — empty Set on
  fresh load → tab hidden until user toggled the Water visualization layer on.
- `showEventsTab` required `llmStatus.schemaVersion === 'v2' || 'v3'` — the
  field is undefined between deploy and the first cron-driven extraction
  (specifically a regression introduced by Phase 27.4.6 itself: the
  fire-and-forget extraction that used to fire on the first `/api/events`
  hit no longer exists, so `schemaVersion` stays undefined longer than before).

Fix: `showWaterTab = true`; `showEventsTab = shouldRenderDashboard()`; Events
body defaults to V3 when `schemaVersion` is unset (V2 is now the explicit
override). Snap-back effect trimmed to Sites only. 3 test files updated;
1929/1929 pass; tsc clean. CLAUDE.md "DevApiStatus Events tab" note refreshed.
