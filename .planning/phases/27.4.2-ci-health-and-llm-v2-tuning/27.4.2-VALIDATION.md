## Sampling Rate

- **After every CI task commit:** Run `npx vitest run src/__tests__/filters.test.ts` (quick)
- **After every CI plan wave:** Run `npx vitest run` (full) + 4 gates above
- **After every tuning sub-lever commit:** Run `npx tsx scripts/eval-replay.ts` (resolver-only GT replay, ~50s warm cache)
- **At every wave-boundary checkpoint (tuning):** Trigger `/api/events?force=true`, capture `evalScore` + `provenanceCounts` + `watchdogTimeoutCount` from `/api/events/llm-status`
- **Before `/gsd-verify-work`:** Full vitest suite green + all 4 CI gates green + final production run meets D-13 stop criteria
- **Max feedback latency:** ~50s (GT replay) for tuning loop; ~2min (full vitest) for CI wave
