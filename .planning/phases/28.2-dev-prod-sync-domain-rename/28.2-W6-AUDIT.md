## Audit Procedure

### Local Pass (Task 4 — smoke check, NOT the gating evidence)

1. `npm run dev` (Vite + Express via tsx)
2. `API_BASE_URL=http://localhost:5173 DASHBOARD_PASSWORD=<dev-default> npx vitest run src/__tests__/api-connectivity.test.ts`
3. Record pass/fail per endpoint in the `Local pass` column.
4. For each FAIL: diagnose via curl + DevApiStatus modal, fix, re-run.

### Prod Pass (Task 9 — phase-close gate per D-25)

1. Trigger `.github/workflows/prod-connectivity-audit.yml` from GitHub Actions UI (manual `workflow_dispatch`).
2. Workflow runs both `api-connectivity.test.ts` (smoke) and `rate-limit.test.ts` (D-30 companion) against `https://otg-iran-monitor.vercel.app` with `DASHBOARD_PASSWORD` Bearer.
3. Workflow writes `audit:connectivity:last-result` to Upstash Redis (7d TTL).
4. The merged DevApiStatus API Health tab reads `/api/audit-status` and surfaces the green banner `All 16 endpoints connecting (last verified <date> via prod audit).`.
5. Record pass/fail per endpoint in the `Prod pass` column.
