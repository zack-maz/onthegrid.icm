Ethnic alpha (140 / ~55%) stays in `ethnicGroups.ts` as `ETHNIC_ALPHA` (alpha is a rendering attribute, not a brand color).
- **Five entity color D-13-spec-vs-runtime drifts surfaced and resolved with RUNTIME values authoritative.** Per W5 Pattern 3, runtime colors preserved byte-identically; CLAUDE.md updated to match. If operator wants the prior D-13 spec values to become runtime, that is a separate explicit decision in a follow-up phase.
