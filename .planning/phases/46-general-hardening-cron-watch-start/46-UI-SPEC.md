# Phase 46 — UI Design Contract

> Visual and interaction contract for the **two new read-only operator observability
> blocks** rendered inside the **API Health tab** of `src/components/ui/DevApiStatus.tsx`:
>
> 1. **Rate-limiter block** (HARD-01) — per-tier limit config + recent HTTP-429 counts,
>    read from the existing `/api/operator-status` aggregator.
> 2. **Cron freshness / missed-run surface** (HARD-02) — `unknown` / `missed` / `healthy`
>    per-cron state, read from the existing `/api/health` (`missed` arrives as a **sibling
>    field**, never a `status`-enum value — RESEARCH Landmine 1/2).
>
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Brownfield additive hardening — NOT a redesign.** The design system is **already
> locked** by `45-UI-SPEC.md` (AUTHORITATIVE), the Tailwind v4 `@theme` block at
> `src/styles/app.css:3`, `src/lib/colorBridge.ts` (D-13 single source), and the two
> Phase-45 atoms (`MetricRow.tsx`, `Sparkline.tsx`). **Every token below is LIFTED from
> Phase 45 / live canonical code — never re-derived, never invented.** This phase adds
> two blocks of telemetry, not one pixel of new visual language.
>
> **Governing rules (carried verbatim from Phase 45):**
>
> 1. **No net-new visual language** — render within the off-the-grid operator-console
>    block idiom: `text-[9px]`, `uppercase tracking-wider text-white/40` headers,
>    `mt-2 border-t border-white/10 pt-2` section separators (Phase 44 D-13 / Phase 45).
> 2. **The WAI-ARIA tablist DOM is FROZEN byte-stable** (Phase 45 D-08 / CONTEXT D-05).
>    Both new blocks render **inside** the existing
>    `role="tabpanel" aria-labelledby="tab-api-health"` container (DevApiStatus.tsx:968).
>    No new tab, no tab-id change, no roving-tabindex change.
> 3. **Reuse the Phase-45 atoms** — `<MetricRow>` for every 429-count / cron-freshness
>    number; `<Sparkline>` for any trend-over-time. Do not fork or re-implement them.
> 4. **Every color from `@theme` / colorBridge — zero inline hex** (CLAUDE.md §Color
>    Tokens / DASH-READ-03).

| Destructive     | `--color-status-degraded` (`#f97316`) / `--color-accent-red` / `text-red-400`                                                         | The `MISSED` cron state + a non-zero 429 surge (read-only signals — no destructive _action_ in this phase). |

**Accent reserved for (explicit list — never "all interactive elements"):**

- **Cron run-state badge** — the load-bearing accent of this phase:
  - `healthy` → `--color-status-healthy` (green) — tick within `expected + grace`.
  - `missed` → `--color-status-degraded` (orange/red) — the distinct **`MISSED`** alarm state; this is the clear degraded signal the CONTEXT constraint requires. Renders as an orange/red badge + `●` bullet so a stalled cron pops out of the otherwise-neutral block.
  - `unknown` → neutral `text-white/40` (NOT an accent) — "never fired yet"; intentionally understated so it never reads as an alarm (it is the pre-first-tick null state, not a failure).
- **Rate-limiter 429 volume (optional tint)** — a recent-429 count of `0` stays neutral `text-white/60`; a non-zero recent count MAY tint the value to `--color-status-warning` (amber) so load-shedding is visible. Discretionary; default neutral if simpler.
- **`Sparkline` last-point tint** (only if a trend ring is added for 429 counts or cron freshness) — neutral muted stroke; ONLY the latest point tints to a semantic `@theme` token on threshold cross (the existing `Sparkline` contract; `var(--color-status-degraded)` default). Reuse the atom as-is.

No new decorative accent. The neutral `white/N` ramp carries ALL non-status structure. **Zero inline hex** — grep gate (`#[0-9a-fA-F]{3,6}` / `rgba(`) MUST return zero new matches in the touched API-Health code.

**State → visual mapping (the MISSED requirement, explicit):**

| Cron run-state | Source                                                                  | Badge color token         | Glyph                           | Reads as             |
| -------------- | ----------------------------------------------------------------------- | ------------------------- | ------------------------------- | -------------------- |

| `missed`       | `missedRun=true` (null OR stale past `expected+grace` after first fire) | `--color-status-degraded` | `●` orange/red + `MISSED` label | **alarm / degraded** |
| `unknown`      | pre-first-tick null                                                     | neutral `text-white/40`   | `○` muted                       | "not yet" (no alarm) |

## Degraded-State Convention (carried from Phase 40/44/45 — honesty)

Degrade-open is preserved exactly; the restyle never changes the contract:

- **Muted placeholder pattern:** `text-white/30 italic` `— no data ({reason})` with the specific cause.
- **Rate-limiter block:** `opStatus.rateLimiter == null` (aggregator unreachable OR the block degrade-opened server-side) → muted placeholder, no crash.
- **Cron block:** `/api/health` response missing the `missedRun` sibling (older server, forward-compat) → muted placeholder OR self-hide, matching the host's established empty behavior for that group.
- **Sparkline (if used):** self-hides (`return null`) below 2 points until the ring fills — correct, not a defect (existing atom behavior).
- **Route stays 200, no block throws.** New blocks change empty renders' styling only, never the error contract.
