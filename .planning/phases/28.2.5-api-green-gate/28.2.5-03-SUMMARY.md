## Decisions Made

- **4.0° Manhattan, not 5.0°.** Per CONTEXT D-05 Claude's Discretion: at 4° (~400km worst case) every Iran-bbox position from (0,20) to (50,80) has multiple candidate facilities given the ~305-facility post-27.3.2 grid. 5° would resolve to samples in entirely different climate regions (e.g., Caspian → Persian Gulf), defeating the regional 30-day metric's coherence.
- **100km hint threshold.** Per RESEARCH Open Question 3: the boundary where the widened 4° cutoff starts returning samples that the tight 2° (~200km Manhattan ≈ ~150km Euclidean) cutoff used to reject — operators see the hint exactly when the new pipeline is doing more work than the old one.
- **`bestDistDeg * 111 km/°` for distanceKm.** Upper bound for 1° latitude (~111km); longitude scales by `cos(lat)` (~0.85 at 32°N) so this is a slight overestimate. For a "is this far?" hint, slight overestimate is operator-honest (worst-case distance disclosed). Per RESEARCH Open Question 2.
- **`bestDistDeg >= 4.0` (literal `<` boundary).** Test C2 locks this exact value — drift to 5.0, ∞, or removing the bound entirely fails the test LOUDLY.
