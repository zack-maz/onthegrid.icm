# Phase 28.2.5 — Validation Strategy

> Per-phase validation contract for feedback sampling during execution.

---

## Test Infrastructure

| Property               | Value                                                                             |
| ---------------------- | --------------------------------------------------------------------------------- |
| **Framework**          | vitest (jsdom for client, node for server)                                        |
| **Config file**        | `vite.config.ts` (test.alias for jsdom map mocks); `vitest.config.ts` if separate |
| **Quick run command**  | `npx vitest run --no-coverage` (single targeted file when iterating)              |
| **Full suite command** | `npx vitest run` (all) — includes `npx vitest run server/` for node-side          |
| **Estimated runtime**  | ~30–45 seconds full suite                                                         |

---

## Sampling Rate

- **After every task commit:** Run targeted `npx vitest run <file>` for the touched test file
- **After every plan wave:** Run `npx vitest run` (full suite) + `npm run build` (tsup + tsc)
- **Before `/gsd-verify-work`:** Full suite must be green AND `npm run lint` must show 0 errors
- **Max feedback latency:** ~10 seconds for targeted run, ~45 seconds for full suite
