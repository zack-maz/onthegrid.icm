### `src/components/map/layers/WeatherOverlay.tsx` (component, event-driven hover)

**Analog:** Same file — `findNearestPrecip` (L77-93) returns bare `PrecipitationData | null`; D-05 widens cutoff and changes return shape.

**Existing function (lines 77-93):**

```typescript
function findNearestPrecip(
  lat: number,
  lng: number,
  data: PrecipitationData[],
): PrecipitationData | null {
  let best: PrecipitationData | null = null;
  let bestDist = Infinity;
  for (const p of data) {
    const d = Math.abs(p.lat - lat) + Math.abs(p.lng - lng);
    if (d < bestDist) {
      bestDist = d;
      best = p;
    }
  }
  // ~2 degrees ≈ 200km — precip is a regional 30-day metric, coarse matching is fine
  return bestDist < 2.0 ? best : null;
}
```

**Mirror for D-05:** widen the `bestDist < 2.0` threshold (CONTEXT suggests ~4°; final value picked from precip-grid spacing per Open Question 2). Refactor return shape to `{ value: PrecipitationData; distanceKm: number } | null`. Convert Manhattan degrees to Euclidean km at lat-band ≈ Iran (~111 km/° latitude × cos(lat) for longitude — or use simple `degrees * 111` upper-bound for the hint copy).

**Tooltip render block (lines 117-125) — pattern for distance hint:**
